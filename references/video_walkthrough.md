## 视频演示了什么

先让 AI 整理与小林聊天中的主要话题、已定安排和待确认问题，保存带消息引用的报告；再追问门票有没有订。AI 在同一批记录里找到一条 10:22 的消息：科技馆是雨天备选，门票尚未预订。

演示使用专门构造的九条虚构消息，不是真实私聊的匿名改写。回复和报告由模型在录制时生成，不是预写结果。视频从安装完成、已有聊天快照后开始，没有演示首次安装、账号配置或 Windows 微信实时采集。

处理自己的数据前，请先按[使用说明](../README.md)安装完整 Skill，配置账号和源目录，并确认本次授权的联系人、时间和任务。

## 数据和结果从哪里来

- 联系人小林及范围内九条消息均为专门构造的合成记录。保存快照的消息覆盖截止时间为 `2026-10-22T14:00:00+08:00`。
- 已安装的 Skill 实际执行了 `collect --snapshot`、`context`、`save-analysis` 和 `search`。读取的是明确选定的已保存合成快照，画面中没有实时采集或解密 Windows 微信。
- 回复和报告由已配置模型在录制过程中实际生成，不是预写或重放。最终展示报告的哈希与保存版本一致，全部九个引用 ID 都对应本次请求的上下文；门票搜索命中一条，时间为 10:22。

## 画面是怎样录制的

- 真实 Hermes 命令行界面运行在 Linux X11。AI 通过 tmux/xdotool 自动驱动鼠标移动、点击、输入和滚动，不是人类手工输入，也不是动画模拟界面。
- 连续原片为 1600×1000、25 帧/秒、5328 帧、213.12 秒。批注版为 1600×1120，帧数与时长相同，无音轨。
- 后期只在原画面下增加中文批注，并加黄色重点框。没有裁切原画面、剪辑、变速、替换回复或插入成功截图；真实处理和等待时间都保留。画面和烧录批注均为中文，本次文档改写没有修改视频像素。
- 画面保留模型名称和部分开发路径。公开前检查过选定的终端文本和代表性画面，未发现明显凭据、真实联系方式或真实私聊。这不等于逐像素的法证审计。

## 哪些内容没有演示

首次安装、账号配置、Windows 实时采集、仅在 WAL 中的近期消息和媒体正文处理均未录制。Linux X11 的录像也不能证明原生 Windows 或 macOS 录屏后端已经通过验证。
